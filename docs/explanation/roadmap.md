# 局限与路线图

## 现在的局限

- **没有导入按钮。** 已有的录音只能用 HTTP 接口导入，见[如何导入已有录音](../how-to/import-recordings.md)。
- **iOS 要自己构建。** App 不在 App Store 上；用免费 Apple ID 装的 App 7 天后要重装。
- **大模型和默认的语音识别在云上。** 全本地需要 `ENGINE=local`（远场录音比千问差，见[语音识别评测](./asr-benchmark.md)）加上你自己运行的大模型服务。
- **短对话没有摘要。** 说话不到 60 秒的对话不调大模型，标题取第一句；进行中时点「立即总结」的除外。

## 路线图

- **导入**：在 App 或命令行里直接导入已有的录音文件。
- **桌面端分栏**：宽屏左边列表、右边详情。
- **人物名片**：在已有的人物卡片上加上最近聊了什么。
- **播放器打磨**：对话页的底部播放条和跟读高亮继续改进。

路线图会变；最新的讨论在 [GitHub issues](https://github.com/suyiiyii/alldayrec/issues)。
