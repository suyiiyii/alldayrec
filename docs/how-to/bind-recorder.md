# 如何绑定录音设备

蓝牙录音设备（比如 [LR-P3](../reference/hardware.md)）要先绑定到一台手机。绑定后它开始录音：手机在附近时实时上传，不在时存进它的卡里，手机回来后在后台补传。没绑定时它不录音，App 用手机麦克风录。

## 绑定

1. 在 App 里打开 **我的 › 录音设备**，点 **添加录音设备**。
2. 页面会列出还没给的权限（蓝牙或「附近的设备」、通知、后台运行），逐个允许。
3. 打开录音设备（插上充电线即可）。列表里会出现附近的录音设备。名字印在设备上；附近有几台时，信号最强的那台标着「最近」。
4. 点它旁边的 **绑定**。

列表里标着「已绑定其他手机」时，可以点 **强制绑定**：绑定到这台手机后，原来那台手机就连不上它了。标着「正连着其他手机」时，先在那台手机上解除绑定，或者关掉那台手机的蓝牙。

## 解除绑定

在 **录音设备** 页点 **解除绑定**。

- 录音设备在附近时：它会忘掉所有手机、停止录音，卡上的录音会先取回。这台手机改用手机麦克风。
- 录音设备不在附近时：只在这台手机上解除，它自己还记着绑定、会继续录音。以后可以在添加时强制绑定。
- iPhone：系统自己的配对记录 App 删不掉。解除后到 **设置 › 蓝牙 › 设备名 › 忽略此设备**；以后要在这台 iPhone 上再绑定它，必须先忽略。

## 换手机后卡上的旧录音

待补充：录音设备换绑到另一台手机后，卡上绑定之前录的音频会不会上传。

没有录音设备的话，可以按 [`hardware/lr-p3/README.md`](https://github.com/suyiiyii/alldayrec/blob/main/hardware/lr-p3/README.md) 自己做一个 LR-P3。
